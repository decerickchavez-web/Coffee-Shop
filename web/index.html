About the System

A Coffee Shop Management System for Team Dream Cafe.

Modules

  • Order taking with size, quantity and add-ons
  • Live order summary and peso totals
  • Checkout with discounts, cash and change
  • Printable receipt and saved order history
  • Inventory with automatic stock deduction
  • Sales report with best sellers

How it is built

  • Graded deliverable: Java 17 + Swing (OOP, GUI)
  • Model: MenuItem, Drink, AddOn, OrderItem, Order
  • Inheritance and polymorphism in pricing
  • Strategy pattern for discounts
  • This browser demo: HTML, CSS and vanilla JavaScript
  • Same menu, prices and rules as the Java build
